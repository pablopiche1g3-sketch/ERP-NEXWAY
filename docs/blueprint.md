# **App Name**: ERP Login

## Core Features:

- Login Form Display: Render a standard login form with input fields for username and password.
- Credential Input: Allow users to securely enter their username and password into dedicated input fields.
- Password Visibility Toggle: Provide a toggle option to show or hide the entered password for better usability.
- Form Submission: Include a button to submit the entered credentials, preparing for backend authentication.

## Style Guidelines:

- Primary color: Muted deep blue-grey (#476685) to convey professionalism and reliability. This color will be used for key interactive elements and prominent text.
- Background color: A very light, almost white, cool grey (#F3F5F6), providing a clean and unobtrusive canvas for the application content.
- Accent color: A vibrant yet clean green-blue (#26D995) for calls-to-action, success indicators, and interactive highlights, offering a refreshing contrast to the primary palette.
- Headline and body text font: 'Inter' (sans-serif) for its modern, highly readable, and neutral appearance, ensuring clarity and legibility across all content.
- Utilize simple, line-art style icons for form fields (e.g., user icon for username, lock icon for password) to maintain a clean and professional aesthetic.
- A minimalist, centered layout for the login form, focusing user attention directly on the necessary input fields without distractions. Sufficient white space will ensure a breathable and uncluttered appearance.
- Subtle hover effects and smooth transitions on form elements and buttons to provide visual feedback without being overly distracting or playful.
